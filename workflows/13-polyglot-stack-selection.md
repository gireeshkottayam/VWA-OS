# Polyglot Stack Selection Workflow

1. Read project requirements.
2. Determine project type.
3. Determine deployment target.
4. Inspect hosting/environment.
5. Determine user/team capability.
6. Generate candidate architectures.
7. Generate candidate technology stacks.
8. Score compatibility, complexity, maintenance, performance, security and cost.
9. Select the simplest suitable stack.
10. Create STACK-DECISION.md.
11. Lock the stack after approval.
12. Route implementation to language/framework specialists.
13. Verify build and deployment compatibility.
14. Document the final decision.
