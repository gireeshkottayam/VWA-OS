# Agent Safe Extension Workflow

1. Detect requested capability.
2. Search existing agents.
3. Read relevant existing agent definitions.
4. Determine whether capability already exists.
5. If missing, create a new specialist or extension.
6. Do not overwrite the original.
7. Record the addition in `core/agent-change-log.md`.
8. Update routing only after review.
9. Run structure/behavior validation.
10. Record evidence.
