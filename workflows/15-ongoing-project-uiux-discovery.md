# Ongoing Project UI/UX Discovery Workflow

Use when VWA-OS joins a project that is already being developed.

1. Read project state and existing documentation.
2. Inspect routes and source structure.
3. Inspect assets and image references.
4. Inspect existing design tokens and components.
5. Render representative pages.
6. Capture current visual baseline.
7. Identify business/product type.
8. Identify user journeys.
9. Identify strengths to preserve.
10. Identify usability and visual gaps.
11. Select an appropriate modern design direction.
12. Create PROJECT-UX-BASELINE.md.
13. Create UX-CHANGE-PLAN.md for material changes.
14. Implement incrementally.
15. Compare before/after.
16. Verify responsive, accessibility, SEO and performance impact.
