# Project Documentation Completion Workflow

1. Discover project architecture.
2. Discover admin routes and menus.
3. Discover public routes.
4. Discover data models and integrations.
5. Discover deployment/platform configuration.
6. Map admin actions to frontend reflections.
7. Build the documentation baseline.
8. Generate the applicable documentation pack.
9. Register secure credential locations without exposing secrets.
10. Mark unknowns as UNKNOWN/UNVERIFIED.
11. Validate documentation against implementation.
12. Generate handover checklist.
13. Generate project completion report.
14. Re-run documentation checks whenever implementation changes.
