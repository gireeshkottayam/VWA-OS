# Workflow 19 — Admin App Discovery & Generation

1. Discover the existing admin panel.
2. Discover roles and permissions.
3. Discover CRUD and workflows.
4. Discover APIs and data models.
5. Map admin actions to public effects.
6. Identify missing APIs/contracts.
7. Create ADMIN-APP-BLUEPRINT.md.
8. Validate blueprint against evidence.
9. Define navigation/screens.
10. Implement the smallest complete vertical slice.
11. Verify authentication/authorization.
12. Verify API → database behavior.
13. Verify public reflection.
14. Repeat feature by feature.
15. Document final wiring.

Never build a fake admin app against mocked endpoints when a real connected application is required.
