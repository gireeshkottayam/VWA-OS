# Document Creation Workflow

1. Discover requirements, source files, evidence and brand assets.
2. Classify the document type.
3. Create the outline.
4. Generate editable source first where practical.
5. Fact-check important claims.
6. Render PDF/DOCX/XLSX/PPTX as required.
7. Inspect the final artifact visually and structurally.
8. Validate accessibility.
9. Assign version, date, status and change history.
10. Package source + final artifact + validation evidence when appropriate.
11. Release only after required gates pass.
