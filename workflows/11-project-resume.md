# Project Resume Workflow

1. Read PROJECT-RESUME.md.
2. Read PROJECT-STATE.json.
3. Read TODO.md.
4. Read DECISION-LOG.md.
5. Read CHANGELOG.md.
6. Inspect git status and recent commits.
7. Inspect relevant agent/workflow definitions.
8. Identify incomplete or blocked tasks.
9. Verify that existing agents have not been overwritten.
10. Select the first unblocked TODO according to priority.
11. Reproduce current state before editing.
12. Continue with evidence collection.
13. Update state and TODO after verification.
