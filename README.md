# VWA-OS v1.6.0 — Universal Software Engineering Agent

A technology-neutral engineering intelligence layer for **Antigravity + OpenCode** on **Windows and macOS**.

## Purpose

Build, modify, debug, test, secure, optimize, document and release software without forcing the developer into Node.js or any other predetermined technology stack.

## Install/update

Existing VWA-OS installation:

```powershell
git -C .vwa-os pull origin main
```

Fresh installation:

```powershell
git clone https://github.com/gireeshkottayam/VWA-OS.git .vwa-os
```

Then read the appropriate integration guide:

- `integrations/antigravity/INSTALL.md`
- `integrations/opencode/INSTALL.md`

## Important

> **Do not assume Node.js. Detect the project first.**

The agent detects the actual language, framework, runtime, package manager, build system and test system from project evidence.

## Strict no-overwrite rule

The agent must protect user changes, uncommitted Git work, working architecture and existing agents. High-impact replacement or destructive operations require explicit authorization.

## Language strategy

The agent supports evidence-driven workflows for a broad range of languages including C/C++, C#/.NET, Java, Kotlin, Swift, Objective-C, Go, Rust, Python, PHP, Ruby, JavaScript, TypeScript, Dart/Flutter, Elixir, Erlang, Haskell, Scala, R, Julia, Perl, Lua, Fortran, COBOL, Assembly, PowerShell, Shell, SQL, Solidity, HTML/CSS and other discovered technologies.

For an uncommon language, it discovers the project's real compiler/interpreter/build/test conventions rather than inventing support.
