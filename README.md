# ⚡ QUICK START — INSTALL VWA-OS FIRST

> ## 🚀 INSTALL VWA-OS INTO AN EXISTING PROJECT
>
> **Already building a website, app or software in Antigravity or OpenCode?**
>
> You do NOT need to rebuild your project.
>
> You do NOT need to convert your project to Node.js.
>
> You do NOT need to replace your existing Git repository.
>
> VWA-OS can be added as an intelligence, governance and workflow layer to your existing project.
>
> ---
>
> ## 🤖 ANTIGRAVITY — INSTALL FROM TERMINAL
>
> **1. Open your existing project in Antigravity**
>
> **2. Open the Antigravity Terminal**
>
> **3. Run:**
>
> ```powershell
> git clone https://github.com/gireeshkottayam/VWA-OS.git .vwa-os
> ```
>
> VWA-OS will be installed inside:
>
> ```text
> .vwa-os/
> ```
>
> **4. Then tell Antigravity:**
>
> ```text
> Read and follow .vwa-os/AGENTS.md and all relevant VWA-OS agents, workflows, skills, integrations and governance files before modifying this project.
>
> First inspect and understand the existing project.
>
> Do not assume Node.js or any particular programming language, framework or architecture.
>
> Discover the existing technology stack, project structure, frontend, backend, APIs, authentication, database, storage, integrations, deployment configuration, UI/UX and existing admin system.
>
> Create an evidence-based project and platform wiring map.
>
> Do not modify the project until the discovery and implementation plan are complete.
>
> Follow the strict VWA-OS no-overwrite rule.
> ```
>
> **VWA-OS is now available to your Antigravity project.**
>
> ---
>
> ## 🔄 UPDATE VWA-OS FROM GITHUB
>
> If VWA-OS is already installed in your project and you want the latest version:
>
> ```powershell
> git -C .vwa-os pull origin main
> ```
>
> Then tell Antigravity:
>
> ```text
> VWA-OS has been updated from GitHub.
>
> Read the updated .vwa-os/AGENTS.md, agents, workflows, integrations, skills and governance files.
>
> Compare the updated VWA-OS capabilities with the current project before making any changes.
>
> Do not overwrite existing project functionality.
> Do not replace existing architecture without evidence and approval.
> ```
>
> ---
>
> ## 🧩 OPENCODE — INSTALL
>
> Open the existing project in OpenCode and use its terminal:
>
> ```powershell
> git clone https://github.com/gireeshkottayam/VWA-OS.git .vwa-os
> ```
>
> Then instruct OpenCode:
>

>

>
> Do not assume Node.js or any particular technology stack.
>
> Discover the project's programming language, framework, architecture, frontend, backend, APIs, authentication, database, storage, integrations, admin panel and deployment environment.
>
> Create an evidence-based project and platform wiring map before modifying anything.
>
> Follow the strict no-overwrite policy.
> ```
>
> ### Update VWA-OS in OpenCode
>
> ```powershell
> git -C .vwa-os pull origin main
> ```
>
> ---
>
> ## ⚠️ IMPORTANT
>
> **DO NOT run this inside your project:**
>
> ```powershell
> git clone https://github.com/gireeshkottayam/VWA-OS.git .
> ```
>
> The `.` means the current directory and may create conflicts with an existing project.
>
> Always install VWA-OS into:
>
> ```text
> .vwa-os
> ```
>
> Your existing project Git repository remains untouched.
>
> Your project structure should look approximately like:
>
> ```text
> YOUR-PROJECT/
> │
> ├── your-existing-files/
> ├── your-existing-source/
> ├── your-existing-config/
> ├── .git/
> │
> └── .vwa-os/
>     ├── agents/
>     ├── core/
>     ├── workflows/
>     ├── integrations/
>     ├── skills/
>     ├── docs/
>     └── ...
> ```
>
> **Never copy the VWA-OS `.git` directory into the project's root.**
>
> **Never delete or replace the project's existing `.git` directory.**

# 🎯 WHAT IS VWA-OS?

VWA-OS is an evidence-driven Visual Web Agent Operating System designed to work with AI development environments such as Antigravity and OpenCode.

It provides a structured intelligence layer for:

- Project discovery
- UI/UX design
- Web development
- Application development
- Mobile development
- Desktop software development
- API development
- Platform architecture
- Platform wiring
- Debugging
- Integration repair
- SEO
- Accessibility
- Performance
- Security
- Documentation
- Admin applications
- Testing
- Deployment
- Release engineering
- Project maintenance

The goal is not simply:

> "Generate some code."

The goal is:

> **Understand the project → Design correctly → Build correctly → Connect everything → Verify everything → Document everything → Deliver a maintainable platform.**
