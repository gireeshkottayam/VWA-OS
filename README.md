

## v1.2.1 Continuity and Agent Governance

VWA-OS now includes project resume/state/TODO management, document continuity agents, Antigravity and OpenCode integration instructions, and a strict no-overwrite policy for existing agents.

**Protected principle: extend, don't destroy.**

## v1.3.0 — Polyglot Engineering & Intelligent Stack Selection

VWA-OS now evaluates project requirements, environment, user capability and deployment constraints before selecting a technology stack. Node.js is no longer assumed by default for websites or other projects.

The stack is documented and can be locked before implementation. Stack changes require evidence and explicit approval.

## v1.4.0 — Adaptive UX/UI & Project Documentation Intelligence

VWA-OS now understands ongoing projects before changing their UI/UX and can generate an evidence-driven, end-to-end documentation and handover pack. The release emphasizes bright, energetic, positive visual design, deliberate use of modern design concepts, admin-to-frontend mapping, secure credential handling and project continuity.
