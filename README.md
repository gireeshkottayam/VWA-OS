# VWA-OS v1.1.0

Enterprise Visual Web Agent Operating System for evidence-driven web design, development, debugging, accessibility, performance, security, SEO and release engineering.

Core loop: **Inspect → Reproduce → Plan → Implement → Verify → Regress → Gate → Ship**

v1.1 adds specialist visual, asset, design, browser, evidence, SEO, performance, security and release agents.

This package contains no `.git` directory. Clone your live repository first, then copy this package's contents into that clone.
