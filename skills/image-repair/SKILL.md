# Image Repair Skill

1. Search the project for the referenced asset.
2. Verify exact filename and case.
3. Verify public/static serving path.
4. Check network response and MIME type.
5. Check intrinsic dimensions.
6. Validate CSS sizing/object-fit/object-position.
7. Add a deliberate fallback only when the design requires one.
8. Re-render and verify no broken image state remains.
