# VWA-OS v1.2.0 — GitHub Desktop Upgrade

This is an upgrade patch for your EXISTING VWA-OS repository.

1. Download and extract this ZIP.
2. Open GitHub Desktop and select your existing VWA-OS repository.
3. Choose Repository → Show in Explorer.
4. Open the extracted upgrade folder in another Explorer window.
5. Copy everything inside the extracted folder.
6. Paste into the existing VWA-OS repository.
7. Replace files when Windows asks.
8. Do NOT delete, move or copy `.git`.
9. Return to GitHub Desktop and review Changes.
10. Commit message:
   Release VWA-OS v1.2.0 — Document Automation Upgrade
11. Click Commit to main.
12. Click Push origin.
13. Verify `agents/document/`, `templates/`, `workflows/09-document-creation.md`, and `workflows/10-project-documentation-system.md` on GitHub.

Do not use Add Local Repository or initialize another repository.

If GitHub Desktop unexpectedly shows Publish branch instead of Push origin, stop and verify the existing repository remote before proceeding.
