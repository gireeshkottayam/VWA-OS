# VWA-OS v1.3.0 — Polyglot Engineering & Intelligent Stack Selection

Release Type: Major Release

## Summary

VWA-OS v1.3.0 introduces a Polyglot Engineering layer so Antigravity and OpenCode can build websites, applications, APIs, desktop software, mobile applications, automation systems and other software without assuming Node.js or any single programming ecosystem.

## Major Features

- Technology Decision Agent
- Architecture Selection Agent
- Hosting Compatibility Agent
- User Capability Agent
- Framework Selection Agent
- Dependency Intelligence Agent
- Build System Agent
- Database Selection Agent
- Deployment Agent
- Migration Agent
- Stack Lock Agent
- Environment Safety Agent
- Language Orchestrator
- 19 language/platform specialists
- Stack Decision document
- Stack Change Request workflow
- No-Node-by-Default policy
- Polyglot stack selection workflow
- Stack change control workflow
- Antigravity integration
- OpenCode integration

## Core Principle

"The user defines the outcome. VWA-OS determines the appropriate implementation technology."

## Important Change

A website is no longer treated as synonymous with Node.js, React or Next.js.

VWA-OS evaluates requirements and environment first.

## Supported Language Families

HTML, CSS, JavaScript, TypeScript, PHP, Python, Java, Kotlin, C#, C, C++, Rust, Go, Ruby, Swift, Dart, SQL, Bash and PowerShell.

The architecture remains extensible; unsupported languages can be added as specialists without overwriting existing agents.

## Stack Governance

Once approved, the technology stack is locked.

A stack change requires:
- evidence
- impact analysis
- migration plan
- explicit approval
- updated stack decision
- verification

## Upgrade Path

This release extends VWA-OS v1.2.1. It does not require a fresh Git repository.

Existing `.git` metadata must remain untouched.
Existing agents must remain intact unless explicitly approved for modification.
