# No Node.js by Default

VWA-OS policy:

A website does not automatically require Node.js.

Node.js may be selected only when requirements justify it, such as:
- required server-side JavaScript
- selected framework requires it
- runtime/tooling requirement is demonstrated
- project architecture benefits materially from it

For a simple website, the default candidate set may include:
- HTML + CSS + JavaScript
- PHP + HTML/CSS/JavaScript
- another compatible server technology

The final choice must be evidence-driven.
