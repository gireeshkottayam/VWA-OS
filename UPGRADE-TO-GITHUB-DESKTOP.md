4. Copy **everything inside the extracted package** into the cloned VWA-OS folder.
5. Replace existing files when Windows asks.
6. **Do not delete, move or copy `.git`.**
7. Do not use Add Local Repository or initialize another repository.
8. Return to GitHub Desktop and review Changes.
9. Commit message: `Release VWA-OS v1.1.0 — Enterprise Visual Agent Upgrade`
10. Click **Commit to main**.
11. Click **Push origin**.
12. Verify the new `agents/*`, `workflows/06-08`, `core/evidence-bus.md`, and `core/agent-routing.yml` files on GitHub.
