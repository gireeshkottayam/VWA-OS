# Polyglot Engineering for OpenCode

OpenCode must use VWA-OS technology selection before implementation.

Required checks:
- project type
- hosting/runtime
- user capability
- requirements
- maintenance
- security
- deployment
- dependency complexity

Create STACK-DECISION.md before major implementation.

If stack is LOCKED:
- do not change it silently
- create STACK-CHANGE-REQUEST.md
- explain evidence and impact
- request approval

Node.js is a choice, not a default.
