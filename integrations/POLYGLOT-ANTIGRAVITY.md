# Polyglot Engineering for Antigravity

Before writing implementation code, run the VWA-OS stack selection workflow.

The user may describe only the desired result. Do not require the user to know the programming language.

For every new project:
DISCOVER → ENVIRONMENT → STACK OPTIONS → RECOMMEND → APPROVE → LOCK → BUILD

If the user says "build a website", do NOT automatically choose Node.js.

If Node.js is selected, explain why it is required.
If a simpler compatible stack satisfies the requirements, prefer the simpler stack.

Never change STACK-DECISION.md silently.
Never overwrite existing VWA-OS agents.
