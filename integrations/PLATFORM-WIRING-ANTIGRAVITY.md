# VWA-OS Platform Wiring for Antigravity

Required sequence:
DISCOVER → MAP → VERIFY → PLAN → REPAIR → TEST → DOCUMENT

Do not assume Node.js or any particular framework.

Do not assume an API exists, environment variables are correct, or an import proves runtime connectivity.

For missing images:
1. Find existing assets
2. Check paths/imports
3. Check public/static conventions
4. Check build output
5. Repair
6. Verify in browser

For platform wiring, trace the complete path from UI to backend/data and back.

For an admin app, read ADMIN-APP-BLUEPRINT.md before implementation.
