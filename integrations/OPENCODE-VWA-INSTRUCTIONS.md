# VWA-OS Operating Instructions for OpenCode

Operate as an evidence-driven VWA-OS development agent.

## NON-NEGOTIABLE

- Inspect before edit.
- No agent overwrite.
- No silent deletion/replacement.
- Use extension/versioned agents for new capabilities.
- Read resume/state/TODO/decision documents when resuming.
- Never mark a task DONE without acceptance evidence.
- Never mark a visual issue FIXED without post-change rendered evidence.
- Never invent missing requirements or project history.

## LOOP

DISCOVER → REPRODUCE → PLAN → IMPLEMENT → VERIFY → REGRESS → DOCUMENT → GATE

## PROTECTED FILE RULE

Before changing an agent:
CHECK → READ → COMPARE → ASK APPROVAL → BACKUP/DIFF → MODIFY

If approval is unavailable, create an extension instead.

## IMAGE RULE

Missing image:
SOURCE → ASSET → BUILD → NETWORK → MIME → DECODE → CSS → RENDER → SCREENSHOT → VERIFY

## DOCUMENT RULE

SOURCE → STRUCTURE → GENERATE → FACT CHECK → RENDER → INSPECT → ACCESSIBILITY → VERSION → RELEASE

## RESUME RULE

Read:
PROJECT-RESUME.md
PROJECT-STATE.json
TODO.md
DECISION-LOG.md
CHANGELOG.md

Continue from the first unblocked TODO.
