# Design System Guidance

## Spacing
Use a consistent 4px base scale. Common values: 4, 8, 12, 16, 24, 32, 48, 64, 80, 96, 128.

## Typography
Use a restrained sans-serif family with a strong text hierarchy. For an Apple-like feel, prioritize optical sizing, tight display tracking, generous body leading and limited font weights rather than copying a proprietary font or layout.

## Containers
Prefer a readable max-width with responsive side padding. Avoid arbitrary margins that only work at one viewport.

## Visual quality
Use whitespace, hierarchy, alignment and contrast before adding decoration.
