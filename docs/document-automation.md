# VWA-OS Document Automation

VWA-OS v1.2 adds a document-production layer so the same evidence-driven system can create and validate project documentation.

Supported target formats include Markdown, HTML, PDF, DOCX, XLSX, PPTX and structured JSON/YAML artifacts, depending on the runtime.

Principle: Generate editable source → render final format → inspect final artifact → release with versioned evidence.
