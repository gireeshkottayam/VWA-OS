# VWA-OS v1.6.0 — Universal Software Engineering Intelligence

## Major release

VWA-OS v1.6.0 introduces the **Universal Software Engineering Agent**, an engineering orchestrator for developers using Antigravity and OpenCode on Windows and macOS.

### What it solves

AI coding environments can incorrectly assume that a website or software project must use Node.js. This release replaces that assumption with evidence-driven project discovery and toolchain selection.

### Capabilities

- New software development
- Existing software modification
- Bug fixing and root-cause analysis
- Feature development
- Unit/integration/E2E/regression testing
- Debugging
- Refactoring
- Dependency upgrades
- Code review
- Security review
- Performance review
- Build and packaging
- Release engineering
- Documentation
- Windows/macOS engineering
- Cross-platform engineering
- Multi-language repositories
- Monorepos
- Specialist-agent coordination
- Evidence-based verification

### Technology coverage

Designed to work across C/C++, C#/.NET, Java, Kotlin, Swift, Objective-C, Go, Rust, Python, PHP, Ruby, JavaScript, TypeScript, Dart/Flutter, Elixir, Erlang, Haskell, Scala, R, Julia, Perl, Lua, Fortran, COBOL, Assembly, PowerShell, Bash/Shell, SQL, Solidity, HTML/CSS and other project-discovered languages.

For uncommon languages, the agent uses a toolchain adapter model instead of pretending to have a dedicated specialist.

### Safety upgrade

The release introduces explicit protection for user work, a no-overwrite gate, baseline capture, evidence-based verification and a requirement to report residual risk.

### Core lifecycle

```text
DISCOVER -> CLASSIFY -> PROTECT -> BASELINE -> PLAN -> IMPLEMENT
-> TEST -> DEBUG -> SECURITY -> PERFORMANCE -> VERIFY -> DOCUMENT -> RELEASE
```
