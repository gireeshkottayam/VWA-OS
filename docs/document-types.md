# Document Types

Planning: brief, PRD, SRS, roadmap.
Design: UX specification, design system, sitemap, content model.
Engineering: architecture, API, database, setup, deployment, troubleshooting.
Quality: QA, accessibility, SEO, performance reports.
Business: proposal, quotation, statement of work, status report.
Delivery: user manual, admin manual, handover, release notes and project archive.
