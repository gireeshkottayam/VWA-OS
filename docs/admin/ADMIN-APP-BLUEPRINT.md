## Screen Contract
For every screen record:
- Purpose
- Route
- Roles
- Permissions
- Data
- API calls
- Loading/empty/error/success states
- Validation
- Destructive actions
- Audit event
- Public reflection

Do not implement unknown API/data contracts unless explicitly authorized to create them.
