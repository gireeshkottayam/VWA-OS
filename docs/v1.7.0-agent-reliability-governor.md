- Explicit UNVERIFIED state

## Why this is different

This is not another coding agent. It is a **trust layer** that supervises coding, QA, debugging, UI/UX, security, performance, documentation, wiring and release agents.

## Safety

The Governor never fabricates evidence and never resets Git, erases user work, disables tests or silently modifies production code.

## Release objective

Make verification and trust a first-class part of AI-assisted software development.

**Don't just let an agent say "Done." Make "Done" demonstrable.**
