# VWA-OS v1.5.0 Update

This is an overlay package for an existing VWA-OS repository.

It adds intelligence for wiring websites, APIs, authentication, databases, storage, queues, external services, mobile/desktop clients and deployment.

It also adds an intelligence layer for understanding an existing platform/admin panel and generating a properly mapped admin application.

Copy the package contents into the existing VWA-OS working tree. Do not copy a `.git` folder.
