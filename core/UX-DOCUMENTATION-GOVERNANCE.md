# UX & Documentation Governance

## UI/UX
- Business fit before decoration.
- User needs before trends.
- Modern design concepts are selectable, not mandatory.
- Bright, energetic and positive is the VWA-OS default visual direction.
- Accessibility, performance and maintainability are first-class requirements.
- Existing project strengths must be preserved.

## Documentation
- Documentation is part of the deliverable.
- Admin operations must be documented.
- Frontend reflections must be mapped.
- Platform and deployment must be documented.
- Credentials must be referenced securely, never exposed.
- Unknown information must be marked rather than invented.
- Documentation must be updated with implementation changes.

## Agent Safety
- Never overwrite existing agents without inspection and explicit approval.
- Extend rather than replace.
